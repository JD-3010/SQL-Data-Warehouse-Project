We have 3 different types that we can do a SQL project

## 1. Data Warehousing :
	Its all about how to organize and stnd ructure and prepare the data for further data analysis. It is the foundation of any data analytics.

- "==Organize , Structure , Prepare=="
- ETL / ELT Processing
- Data Architecture
- Data Integration
- Data Cleansing
- Data Load
- Data Modelling

## 2. Exploratory Data Analysis (EDA) :
	In this kind of projects we can learn how to ask the right questions to understand about the data and how to find the most appropiate answer using SQL.

- "==Understand Data=="
- Basic Queries
- Data Profiling
- Simple Aggregations
- Subquery

## 3. Advanced Data Analytics :
	In this kind of advanced analytics project , we will be using advanced techniques in order to answer business questions such as finding trends over time , comparing performance , Sedmenting the data and generation meaningful business dashboard and visualizations.

- "==Answer Business Questions=="
- Complex Queries
- Window Functions
- CTE
- Subqueries
- Reports
