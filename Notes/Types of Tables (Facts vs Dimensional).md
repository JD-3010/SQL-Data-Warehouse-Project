
##### What is Dimensional Tables ?

- It contains **==Descriptive Information's that gives more context==** to the data
- For Eg : We have a product data table , in this table it tells about the product like product name , Product manufactured at , product color etc etc

- This is like a table which is describing the product 

- If we have a table that answer --> **==Who? , What? , Where? .Then this is a Dimensional Table==**
##### What is Fact Tables ?

- It contains **==Quantitative Information that represent events ==**
- Here there are 3 important we have to notice :
	 1. It has Multiple Products / Id's 
	 2. It has Date Informations
	 3. It has Measure and Numbers data

![[Pasted image 20260317110145.png|477]]

- So if we see any table that has been 3 types of data in them ... then we can tell that the table is a Fact Table 

- So if we have an table that answer --> **==How much ? , How many ? and When ? . Then this is a Fact Table==**
