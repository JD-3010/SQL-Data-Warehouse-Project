
**What is Data Modelling ?**
	--> Process of taking Raw Data and organizing it into a meaningful way and putting the new organized data into friendly , easy to understand separate tables and then describe the relationship between those tables / objects 

![[Pasted image 20260317100019.png]]

**We have 3 Different Stages in Data Modeling :**
##### 1. Conceptual Data Model :

- Here the only focus is on the entity/table , we don't go deep inside details we just focus on the entity what type of table is it based on table name or type 

- It does not focus on the details 

- Gives a rough big picture 

![[Pasted image 20260317100429.png|435]]

##### 2. Logical Data Model :

- Here we start to focus on each columns the entities / tables has , for eg : Cust_id, first_name etc

- And we try to connect the relationship of the entities / tables based on those columns . This Data model gives more details on how we can connect tables and which are more relatable to each other 

- Gives the Blueprint 

![[Pasted image 20260317100714.png|433]]

##### 3. Physical Data Model :

- Here we will add more details to each tables like we will mention the column name as well as their datatypes and their length 

- Gives the Implementation idea 

![[Pasted image 20260317100912.png|427]]


--> In this project , we will be using on logical data model
